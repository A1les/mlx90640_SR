MLX90640 温度处理完整说明

从原始子页、运动自适应频域去交错，到时间滤波与单帧 CNN 重建。

原始温度 32×24 → 保留当前观测的去交错 → 时间 EMA → CNN 64×48

同时提供先 CNN 后 EMA 的对照；两条顺序共享运动权重。

本页解释活动 v3 实现。64×48 为重建网格；合成误差与静态波动不能代替真实空间分辨率和测温验证。离线阅读无需联网，外部文献链接需联网打开。

算法与数据流

原始温度与观测保护

传感器有 32×24 个位置，每个棋盘子页更新 384 个。完整温度矩阵来自两个先后读取的子页，不能据此宣称全阵列同一时刻积分。采集适配器记录两个 834 字原始子页、控制寄存器、子页编号、读取时间及温度换算参数；Adafruit 的温度换算函数保持原样调用。

记完整温度矩阵为 R、最新子页掩膜为 C、确认可修补掩膜为 M。M 只能包含较旧子页位置。去交错结果 D 在 M 之外与 R 保持相同 dtype 和原始字节，包括带符号零。该硬约束只属于去交错层，后续 EMA/CNN 是另存的估计。

噪声标定

calibration.fit_profile 在静态录像的指定区间估计逐像元差分尺度与空间残差尺度。MAD 尺度为 1.4826×中位绝对偏差，下限为 1e−8。差分尺度来自相邻完整帧之差；空间尺度来自最新子页十字重建与原始温度的差。两个棋盘奇偶位置分别估计空间尺度。

默认标定区间为第 5 至 17.5 秒，评分阈值取静态评分的 0.999 分位数。历史标定使用 98 帧。程序要求区间连续、子页时间有效、配置不变，并将设备序列号、EEPROM 哈希和 ADC 分辨率设置写入配置。标定本身不证明拍摄场景静止，采集时必须满足这一前提。

运动候选与区域确认

对每个旧位置，检测器比较十字重建残差、单次频域残差和相邻完整帧差分。差分按该位置的静态尺度标准化。十字邻居中的有符号变化需要支持空间残差的方向，避免单个高噪声点独自触发。

约束频域修补

FFT 滤波器围绕棋盘奈奎斯特角频率构造周期高斯抑制区域，宽度 0.22 cycles/pixel，抑制强度 0.75，反射扩展 8 像元。频域滤波器保留直流通道；带掩膜的最终写回并不施加整图均温严格不变的额外约束。

设 K(X)=IFFT(H·FFT(X))，以 X⁰=R 开始，执行 Xᵏ⁺¹=(1−M)R+M K(Xᵏ)。当前共 16 次，同一帧内完成。它使用频域运算及观测约束，没有按照收敛误差自动停止。受限内部估计使用 float32；未选中位置从原始数组直接保留。

完整帧间隔超过 3/16 秒、子页间隔超过 1.5/16 秒、配置不匹配或时间无效时，修补历史重置，当前帧保持原始值。帧间大于零的单调性和控制寄存器一致性也被检查。

时间滤波

EMA 为 Yₜ=αₜXₜ+(1−αₜ)Yₜ₋₁。权重从原生去交错图像 D 计算，上下两条顺序共用同一个权重图。

局部指标为 dilate₃(abs(mean₃(D−G)))，其中 G 是检测器的历史状态。先平均有符号差分，再取绝对值，最后膨胀。基础 α=0.5；指标从 0.9 到 1.8°C 时，α 线性增大至 1。达到上限时局部旁路保持 2 帧。

相邻 D 的差分经 5×5 平均后，绝对变化超过 1°C 的位置占比大于 3% 时，整帧 α=1 并保持 4 帧；持续触发会续期。去交错确认区域经 3×3 膨胀后，局部 α=1 并保持 2 帧，同时清除该处检测历史。第一帧、时间逆序、时间间断及去交错重置会重新建立历史。

α=1 表示当前帧直接进入结果和历史。该判断基于温度变化，缓慢低对比运动可能漏检，真实温度突变也可能触发。固定阈值是工程设置，不是从 CNN 训练得到的参数。

两种顺序与 CNN

上排先 Sₜ=F(Dₜ)，再 Yₜ=α↑Sₜ+(1−α↑)Yₜ₋₁。下排先 Zₜ=αDₜ+(1−α)Zₜ₋₁，再 Vₜ=F(Zₜ)。α↑ 将每个原生权重复制到对应 2×2 输出位置。CNN 非线性和空间邻域运算使两个顺序一般不能交换。整帧 α=1 时，两条结果都等于 F(Dₜ)。局部旁路时，下排 CNN 仍会看到旁边经过时间滤波的输入，不能据单个 α=1 推断局部结果必然相同。

CNN 由五个 3×3 卷积、四个 ReLU 和 PixelShuffle(2) 构成。通道依次为 1→24→24→24→24→4；最终四通道重排为 1×48×64。网络计算 F(T)=bilinear₂(T)+10×PixelShuffle₂(fθ((T−mean(T))/10))。末层零初始化，使初始模型等于双线性插值。参数总量 16,732。训练来源、损失和验证边界见模型卡与训练文档。

输入、输出与结构

输入为摄氏度 float32 [N,1,24,32]，输出为估计摄氏度 [N,1,48,64]。ONNX 发行模型的 N 固定为 1。输入布局为原始行列排列，不旋转、不翻转、不做颜色归一化。

卷积通道为 1→24→24→24→24→4，全部 3×3、stride 1、padding 1，前四层后接 ReLU。输出通过 PixelShuffle(2) 重排。网络学习 (T−mean(T))/10 上的残差，并将残差乘 10 后加到原温度的双线性插值上。末层零初始化。该结构没有时序输入，过去帧只在独立 EMA 中使用。

数据与目标

训练来源为 MlGesture 的 Lepton 温度数据，54,450/13,703/11,742 帧分别用于训练/验证/测试，参与者互不重叠。训练目标为原生 Lepton 图按面积重采样至 64×48 的参考温度图，输入由模拟退化产生。没有真实配准 MLX90640/高分辨率监督，没有利用当前相机的运动录像进行 CNN 配对训练。

损失权重为温度 1、边缘 0.2、一致性 0。历史验证 MAE 为约 0.1426°C。matched 合成测试相对 bicubic 的 MAE 降低约 27.31%，边缘误差降低约 23.97%。这些值描述相对合成参考的误差，不是绝对测温误差。

使用范围

该模型用于研究轻量温度图重建和算法顺序。训练场景以车内近室温手部为主，无法仅凭均值中心化推断它对室外、火灾、高温、远距离微小目标均有效。模型不保证热点峰值、细小间隙或温度极值保持，也不对输入观测施加逐像元硬约束。64×48 输出需要通过独立目标、配准、噪声控制和空间分辨率测试才能获得物理性能解释。

验证与复现

源码迁移后模型结构、参数数量、初始化行为、温度平移性质与反向传播均有自动检查。真实录像回归使用同一个冻结 PyTorch 模型隔离代码整理造成的差异。历史树莓派 ONNX 一致性记录与本次包级回归是不同验证任务；新导出文件应重新执行数值校验和目标设备性能测试。

准备缓存

输出 Lepton 参考缓存、MLX 原生缓存、逐帧索引、可用性掩膜、固定划分和完整 manifest。原始归档不修改。目标目录必须为空或尚不存在，程序不会覆盖既有缓存。缓存包含约 1.4 GB 数值数组，应预留额外空间。

监督样本与损失

对参考温度 H，使用 5×5 高斯模糊、2×2 平均降采样、高斯随机噪声和 0.1°C 量化得到 L。训练模糊标准差在 0、0.5、1.0 中随机选取，噪声标准差从 0–0.2°C 均匀选取。模糊参数和噪声幅值按批次抽取，噪声样本逐元素独立；水平翻转也按批次以 0.5 概率执行。0.1°C 是公开数据的存储步长，不能用作传感器精度声明。

损失为温度 L1 + 0.2×水平和垂直温差的平均 L1。代码计算并记录降采样一致性误差，但选中配置的权重为 0。实际训练没有对 CNN 输出施加原始 MLX 观测的硬约束。当前模糊/噪声模型为模拟假设，尚未辨识当前设备的真实 PSF 和噪声分布。

训练与评价

python -m mlx90640_pipeline.training.train --data data/mlgesture --config configs/thermal_sr_x2.json --run runs/thermal_sr_x2 --device cuda
python -m mlx90640_pipeline.training.evaluate --data data/mlgesture --checkpoint runs/thermal_sr_x2/best.pt --output outputs/test --device cuda

CPU 运行改为 --device cpu。训练使用 AdamW，初始学习率 0.001，余弦下降至 0.00005，权重衰减 1e−5，批次 128，梯度范数裁剪 1.0，共 24 轮。每轮遍历全部训练样本；按验证 MAE 保存 best.pt，末轮状态保存为 last.pt。继续同配置同数据训练可使用 --resume。

验证采用固定种子、模糊 0.5 和噪声 0.1°C。测试分别使用 matched(0.5,0.1)、stronger_blur_noise(1.0,0.2)、outside_training_degradation(1.5,0.3)。评价输出逐帧和按受试者/视角/手势分组统计。总体统计按帧加权，不能视作各受试者等权。测试用于最终评价，不参与梯度更新。

历史选中模型在第 22 轮达到最低验证 MAE，虽然训练计划为 24 轮。新训练受运行环境和算子版本影响，不承诺重新生成相同权重字节。run_metadata.json 记录配置、源文件哈希、数据 manifest 哈希和设备；history.jsonl 记录每轮指标。

温度录像格式与来源追踪

NPZ 容器

读取使用 allow_pickle=False，禁止对象数组。温度数组始终保留摄氏度数值，显示用的 uint8 色彩图不作为数值输入。保存使用同目录临时文件、fsync 和原子硬链接发布，不覆盖已有目标。输出目录所在文件系统需要支持同目录硬链接，常用 ext4 和 NTFS 支持该操作；不支持时保存会明确失败。

字段形状/类型含义
raw_temperature_cN×24×32，float64 或 float32未经本项目插值/滤波的换算温度；采集入口为 float64
times_sN，浮点进程单调时钟，秒；用于帧间间隔，不是 UTC epoch
raw_subpages_u16N×2×834，uint16每次转换的 832 RAM 字、控制寄存器和子页号
latest_subpageN，整数 0/1第二次转换对应的最新子页
conversion_jsonN，Unicode两次转换的发射率、反射温度、芯片温度、电源电压、读取 UTC 等
acquired_at_utcN，Unicode，可选完整帧取得后的 UTC 时间

metadata_json标量 Unicode格式、单位、算法配置、合成/真实标记、会话起点

旧格式可以没有 factory_json，但必须提供旁置的 sensor_factory.json。原始两行 RAM 不能被当成两张完整同步热图；只有对应子页位置属于该次更新。读取时间是主机观察到的转换/读取时间，不是已标定的模拟积分中心。

派生数组

deinterlaced_c 保留原 dtype；其余 CNN/EMA 温度通常为 float32。repair_proposed、repair_eligible、repair_mask 分别表示候选、确认可修补位置和实际发生改写的位置。repair_source 为 0（保留测量）或 3（约束频域估计）。

sr_temperature_c 是 CNN(D)；final_temperature_c 是 EMA(CNN(D))；native_temporal_c 是 EMA(D)；pre_cnn_temperature_c 是 CNN(EMA(D))，此历史字段名表示“CNN 之前做时间滤波”的最终结果，不是 CNN 输入。temporal_native_alpha 为 24×32 权重，temporal_alpha 为复制后的 48×64 权重。两条顺序各自保存更新前历史，便于验证加权公式。

分块与回放

现场采集默认每 256 帧保存一块，避免无限累积内存；记录包括完整原始数据和启用时的派生结果。跨块实时滤波历史连续，但单独回放一块会从首帧重新建立历史。因此不能要求任意截取文件的首帧派生结果等于原实时状态。每块元数据明确标记这一点。

replay 总是从原始温度重算，不信任缓存中的去交错或 CNN 数组。真实输入必须同时具备两个合法子页、16 Hz 棋盘配置和设备信息。子页间隔不合法时保留原数据并禁用该帧修补。格式错误、非有限温度和不支持的模式会报错。

公开范围

原始录像可能含现场内容和设备身份，EEPROM 也属于设备专有标定数据。本仓库不将这些文件放入 Git 或公共源码 ZIP。示例使用确定性的合成数据；其 synthetic=True，RAM 数值为零占位，不能用来推导真实温度换算或宣称采集精度。

树莓派安装与运行

适用环境

目标为具有 I2C 的 Raspberry Pi OS 64 位系统和 MLX90640。数值算法固定使用 16 Hz 子页设置、棋盘模式，理想完整帧率上限约 8 FPS。历史装置在 400 kHz I2C 下约 7.85 完整 FPS，这是已有部署记录，不是对所有设备的保证。

运行前在系统设置启用 I2C，确认用户有设备访问权限。总线速度由操作系统配置，不能依赖 Linux Blinka 的 Python frequency 参数改变总线。历史配置为 dtparam=i2c_arm=on,i2c_arm_baudrate=400000；是否适合当前布线、电容与系统需自行验证。本程序不修改启动配置、不重启系统。

python -m pip install '.[pi]'

采集适配器固定要求 adafruit-circuitpython-mlx90640==1.3.9，因为它记录该版本私有转换接口的输入。驱动升级需要重新验证。现有环境已满足依赖时直接使用，不必重复安装。

单设备读取与资源清理

开始前关闭其他 MLX90640 采集进程。入口使用合作锁，并检查可见进程是否已打开 /dev/i2c-1；它不会自动停止其他程序。锁检测受进程可见性和权限限制，不能替代操作层面的单读者要求。--lock-file 可与现有项目统一合作锁路径。

每次读取有 5 秒超时。错误读取不进入处理历史，累计 5 次错误后停止，不循环重置设备。退出时保存完整帧并释放 I2C 资源。信号处理和 GUI 需要从主线程运行；无桌面时省略 --show。

历史实验与本次检查的区别

历史选中 CNN 的合成 matched 测试相对 bicubic 的 MAE 降低约 27.31%，边缘误差降低约 23.97%。该结果相对于 Lepton 合成参考，不能解释为 MLX 绝对测温精度。历史静态录像中两个顺序的最终平均时间标准差约为 0.2848°C 和 0.2819°C，属于该指定录像的时间稳定性统计。

尚未建立的结论

当前没有经过严格同步、配准、辐射标定的 MLX/高分辨率真值对；没有以 ESF/MTF、已知温度目标或黑体试验确认真实分辨率和测温提升；没有以多设备、室外与高温场景证明全场景泛化。整帧 α=1 可以证明该帧不混入 EMA 历史，但无法证明运动检测从不漏检，也无法消除传感器本身的时间混合。
