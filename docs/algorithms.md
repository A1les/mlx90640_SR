# 算法与数据流

本文描述活动代码 `confirmed_frequency_repair_v3` 和共享权重双顺序后处理。图像尺寸按宽×高表示，NumPy 索引为行、列。

## 原始温度与观测保护

传感器有 32×24 个位置，每个棋盘子页更新 384 个。完整温度矩阵来自两个先后读取的子页，不能据此宣称全阵列同一时刻积分。采集适配器记录两个 834 字原始子页、控制寄存器、子页编号、读取时间及温度换算参数；Adafruit 的温度换算函数保持原样调用。

记完整温度矩阵为 R、最新子页掩膜为 C、确认可修补掩膜为 M。M 只能包含较旧子页位置。去交错结果 D 在 M 之外与 R 保持相同 dtype 和原始字节，包括带符号零。该硬约束只属于去交错层，后续 EMA/CNN 是另存的估计。

## 噪声标定

`calibration.fit_profile` 在静态录像的指定区间估计逐像元差分尺度与空间残差尺度。MAD 尺度为 1.4826×中位绝对偏差，下限为 1e−8。差分尺度来自相邻完整帧之差；空间尺度来自最新子页十字重建与原始温度的差。两个棋盘奇偶位置分别估计空间尺度。

默认标定区间为第 5 至 17.5 秒，评分阈值取静态评分的 0.999 分位数。历史标定使用 98 帧。程序要求区间连续、子页时间有效、配置不变，并将设备序列号、EEPROM 哈希和 ADC 分辨率设置写入配置。标定本身不证明拍摄场景静止，采集时必须满足这一前提。

## 运动候选与区域确认

对每个旧位置，检测器比较十字重建残差、单次频域残差和相邻完整帧差分。差分按该位置的静态尺度标准化。十字邻居中的有符号变化需要支持空间残差的方向，避免单个高噪声点独自触发。

| 参数 | 活动值 |
|---|---|
| 帧间差分的区域支持 | 5×5 内至少 5 个位置超过 2.5 倍差分尺度 |
| 初始种子的区域支持 | 7×7 内至少 3 个种子 |
| 十字残差阈值 | 0.85 倍空间残差尺度 |
| 频域残差阈值 | 1.5 倍频域残差尺度 |
| 频域/十字残差尺度比 | 0.28，历史静态拟合预设 |
| 当前帧强确认 | 5×5 内至少 3 个差分超过 3.5 倍尺度 |
| 前一帧支持 | 5×5 内至少 2 个前帧候选 |

旧像元候选通过临时十字膨胀连接曼哈顿距离为 2 的位置。包含确认支持点的候选连通区域得以保留，但临时桥接点不会成为可写位置。`repair_proposed` 是候选，`repair_eligible` 是确认可写集合，`repair_mask` 是最终实际发生数值改变的位置。

## 约束频域修补

FFT 滤波器围绕棋盘奈奎斯特角频率构造周期高斯抑制区域，宽度 0.22 cycles/pixel，抑制强度 0.75，反射扩展 8 像元。频域滤波器保留直流通道；带掩膜的最终写回并不施加整图均温严格不变的额外约束。

设 K(X)=IFFT(H·FFT(X))，以 X⁰=R 开始，执行 Xᵏ⁺¹=(1−M)R+M K(Xᵏ)。当前共 16 次，同一帧内完成。它使用频域运算及观测约束，没有按照收敛误差自动停止。受限内部估计使用 float32；未选中位置从原始数组直接保留。

完整帧间隔超过 3/16 秒、子页间隔超过 1.5/16 秒、配置不匹配或时间无效时，修补历史重置，当前帧保持原始值。帧间大于零的单调性和控制寄存器一致性也被检查。

## 时间滤波

EMA 为 Yₜ=αₜXₜ+(1−αₜ)Yₜ₋₁。权重从原生去交错图像 D 计算，上下两条顺序共用同一个权重图。

局部指标为 dilate₃(abs(mean₃(D−G)))，其中 G 是检测器的历史状态。先平均有符号差分，再取绝对值，最后膨胀。基础 α=0.5；指标从 0.9 到 1.8°C 时，α 线性增大至 1。达到上限时局部旁路保持 2 帧。

相邻 D 的差分经 5×5 平均后，绝对变化超过 1°C 的位置占比大于 3% 时，整帧 α=1 并保持 4 帧；持续触发会续期。去交错确认区域经 3×3 膨胀后，局部 α=1 并保持 2 帧，同时清除该处检测历史。第一帧、时间逆序、时间间断及去交错重置会重新建立历史。

α=1 表示当前帧直接进入结果和历史。该判断基于温度变化，缓慢低对比运动可能漏检，真实温度突变也可能触发。固定阈值是工程设置，不是从 CNN 训练得到的参数。

## 两种顺序与 CNN

上排先 Sₜ=F(Dₜ)，再 Yₜ=α↑Sₜ+(1−α↑)Yₜ₋₁。下排先 Zₜ=αDₜ+(1−α)Zₜ₋₁，再 Vₜ=F(Zₜ)。α↑ 将每个原生权重复制到对应 2×2 输出位置。CNN 非线性和空间邻域运算使两个顺序一般不能交换。整帧 α=1 时，两条结果都等于 F(Dₜ)。局部旁路时，下排 CNN 仍会看到旁边经过时间滤波的输入，不能据单个 α=1 推断局部结果必然相同。

CNN 由五个 3×3 卷积、四个 ReLU 和 PixelShuffle(2) 构成。通道依次为 1→24→24→24→24→4；最终四通道重排为 1×48×64。网络计算 F(T)=bilinear₂(T)+10×PixelShuffle₂(fθ((T−mean(T))/10))。末层零初始化，使初始模型等于双线性插值。参数总量 16,732。训练来源、损失和验证边界见模型卡与训练文档。
